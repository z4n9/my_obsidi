#Learn 
Confluence - это онлайн система для командной работы с документами.
Программа позволяется организовать взаимодействие внутри команды, делится знаниями, обсуждать проекты, хранить информацию.

### Что там делают:

- пишут техническую документацию
- описывают API
- ведут требования к проекту
- делают инструкции
- сохраняют протоколы встреч
- пишут тест-планы
