8)Usualy in golang we use lowercase. But diffirent types of cases means different accessability. 
For example:
Uppercase for "public"

9)If a package is named **`main`**, then Go builds it as an **executable program**.
If the package is NOT named `main`, Go builds it as a **library**, not a runnable program.
