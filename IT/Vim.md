#Learn 
-Comands:
:!q - quit without saving

:u - undo

:x - save and exit

y - copy
p - paste

dd - delete line

daw - delete word under cursor
caw - delete word under cursor and enter insert mod

w - goes to the next word

v - visual mode

x - deletes one letter in normal mode

:r {file name} - insert another file into current

:! {command} - use terminal command within vim

:enew - adds new empty buffer(whatever this is)

:e {file name} - opens file in new buffer

:bp - buffer previous 
:bn - buffer next
:bd - close buffer

gg - goes to top of the file
shift+g - to the end

Shift+a - insert mode on the end of line
Shift+s - insert mode and removes current line
