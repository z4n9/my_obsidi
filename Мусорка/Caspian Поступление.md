Какие документы необходимо предоставить при подаче заявки на поступление?

Перечень документов

- аттестат или диплом с приложением (оригинал) + копия
- сертификат ЕНТ - ЕСТЬ
- 6 фотографий размером 3х4 - ЕСТЬ
- медицинскую справку формы 075-У - ЕСТЬ
- копия формы 063 (прививочная карта) - ЕСТЬ
- снимок флюорографии - ЕСТЬ
- копию регистрации приписного свидетельства для юношей - ЕСТЬ
- копия удостоверения личности -2 шт - ЕСТЬ
